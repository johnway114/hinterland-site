How to play M4B files

M4B is a common format for audiobooks. This guide explains what an M4B file is, how to play one on each kind of device, and what to do when a file will not open.

What an M4B file is

An M4B file is an MPEG-4 audio file. Its audio is usually encoded with AAC. The format can hold chapters, cover art and one whole book in a single file. It uses the same container as M4A, so the two formats are closely related.

Play an M4B in your browser

The Hinterland web player plays M4B files directly in your browser, with no app to install. Add the file, and the player reads its chapters and remembers where you stopped.

You can drop files onto the page, or add a whole folder, which becomes one book. The player offers playback speeds from 0.75× to 2×, a sleep timer set to 15, 30 or 60 minutes, and buttons to skip back 15 seconds or forward 30 seconds.

Your files stay on your device. They are stored only in your browser, using IndexedDB, and are never uploaded. The web player is free, has no account, no ads and no tracking. It does not sync with the iPhone app or with iCloud. Browsers can clear stored books, so keep the original files.

Play M4B on iPhone and iPad

Apple Books plays M4B audiobooks. The dependable way to add your own file is to add it to Apple Books on a Mac and then sync it to your iPhone or iPad.

Hinterland for iPhone and iPad is coming to the App Store. Until it arrives, Apple Books is the built-in option for audiobooks on your iPhone and iPad.

Play M4B on Mac and Windows

On a Mac, Apple Books can open M4B files. VLC is a free media player for both Mac and Windows, and it plays M4B files. The Hinterland web player also runs on both systems, in your browser.

Play M4B on Android

Many audiobook and media players for Android can open M4B files. Look for one that lists M4B or audiobooks among its supported formats. The Hinterland web player runs in the browser, so you can also try it in Chrome on Android without installing anything.

Why an M4B file will not play

If an M4B file will not open, the cause is usually one of three things.

Protected purchases. Some audiobooks are locked with digital rights management (DRM). Older iTunes Store audiobooks and Audible files in AAX or AA format are examples. These need the seller's own app. The Hinterland web player cannot open them.

A damaged file. An interrupted download or copy can leave a file that will not open. Download it again from the original source and try once more.

An unusual codec. Most M4B files use AAC. A file encoded with a less common codec may not play in every player. Try VLC, which handles many formats.

M4B compared with MP3

An M4B holds a whole book in one file, with chapters built in. An audiobook in MP3 is often split into many files, one for each part. Both formats work in Hinterland, and the web player treats a set of files, or a folder, as one book.

The web player shows the chapters in an M4B file. Use whichever format your audiobook comes in, and keep the original files either way.

Frequently asked questions

Why won't my M4B file play?

Protected purchases need the seller's own app. Older iTunes Store audiobooks and Audible AAX or AA files are examples, and the web player cannot open them. A damaged or incomplete file can also fail, so download it again from the original source. An unusual codec can cause problems too. Try VLC to check.

Is an M4B file the same as an M4A file?

They use the same MPEG-4 container, so the structure is much the same. M4B is the name usually given to audiobooks, which often have chapters.

Are my files uploaded when I use the web player?

No. The web player stores your files only in your browser, using IndexedDB. Nothing is uploaded.

Does the web player sync with my iPhone or iCloud?

No. The web player does not sync with the Hinterland app for iPhone and iPad or with iCloud. It saves your place only in the browser you use.
